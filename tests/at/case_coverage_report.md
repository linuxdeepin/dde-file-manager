## 二、数据来源与统计口径

### 2.1 数据来源

- 原始基线：`tests/at/统信桌面操作系统V25-用例-文件管理器-1173.xlsx`「用例」sheet，共 1173 条，编号唯一。项目内无 `cases_raw.yaml`，以 xlsx 为准。
- AT 用例：`tests/at/yaml/` 下 71 个 `*.suite.yaml`，共 1178 个 suite case。来源关联优先取 `vars.xlsx_id`，其次取 `description` 中的「来源用例编号 / xlsx 用例编号」，再次取 case id 中数字。
- 过滤分类：按用例编号沿用既有 `.trellis/tasks/09-23-at-case-coverage-audit/research/raw-filter-audit.yaml`（新基线 1172 条命中，1 条新增按标准 GUI 处理）。

### 2.2 弱覆盖 / 强覆盖 / 合并批次口径

- **弱覆盖（主口径）**：suite case 必须执行到原始用例对应的**功能入口、操作路径或关键控件**（UI 操作或等价的 CLI/DBus/配置命令），才计为覆盖；仅启动应用后断言预设 `PASS` 标记的「入口烟测」不计入主口径，单列为上界。
- **强覆盖**：suite case 必须执行原始关键操作，并断言原始预期中的关键最终结果，才计为覆盖。本报告不以此为准。
- **基线变更**：以 `tests/at/统信桌面操作系统V25-用例-文件管理器-1173.xlsx`（1173 条）为唯一基线，不再使用旧的 2400 条用例表；过滤分类沿用既有 raw-filter-audit 按编号映射（1172 条命中，1 条新增按标准 GUI 处理）。
- **存量 AT 套件**：`xlsx批次一/二/三批补全`（68 条入口烟测）、`xlsx场景化补全/二/三/四`（合入 88 条）及历史 `xlsx严格*/smoke_*/mainui_*/topui` 等共同参与覆盖计算。

### 2.3 计数与排除规则

- **非 1:1 计数**：一个 suite case 可覆盖多个原始用例，按**原始用例条数**累计；同一原始用例被多个 suite case 覆盖只计一次。
- **不计功能弱覆盖**：① 仅启动应用/打开夹具目录并断言 `PASS_<ID>` 的入口烟测；② `steps` 为空仅断言预制 `PASS` 的伪用例；③ 仅断言进程存活或无关静态控件。
- 恒等式：`总数 = 过滤数 + 可自动化数`；`可自动化数 = 已覆盖数 + 待补数`。

## 四、弱覆盖统计

```
测试用例基线 1173
  ├─ 过滤（AT 无法完成） 653
  └─ 可自动化数         520
        ├─ 已弱覆盖（功能操作口径） 472
        └─ 待补（功能操作口径）     48
        （入口烟测上界：519）
```

- 覆盖率 = 472 / 1173 = **40.24%**
- 可自动化覆盖率（主口径）= 472 / 520 = **90.77%**
- 可自动化覆盖率（入口烟测上界）= 519 / 520 = **99.81%**

### 4.1 AT 用例数（1178）多于转换对标数据（472）的原因

1. **同源拆分/变体**：363 条原始用例被拆成多个 suite case（同一原始 ID 多 case），故 AT 用例数大于原始用例数。
2. **映射到被过滤原有用例**：490 个 suite case 的原始 ID 属于过滤集合，不计入覆盖分子。
3. **无基线来源**：9 个 suite case（PR/动态效果等）不含 V25 编号。
4. **入口烟测未计主口径**：本次批次 68 条 case 仅打开夹具目录并断言 `PASS`，覆盖 88 条原始 ID 但未执行功能操作。
5. **一案覆盖多源**：120 个 suite case 同时关联多个原始 ID，按原始条数累计。

可自动化相关的 suite case 为 679 个，去重后功能弱覆盖 472 条原始用例。

### 4.2 基线变更与存量套件复核

- **基线**：`统信桌面操作系统V25-用例-文件管理器-1173.xlsx`，共 1173 条，编号唯一；旧的 2400 条用例表不再使用。
- **存量套件**：`xlsx批次一/二/三批补全`（68 条入口烟测）、`xlsx场景化补全/二/三/四`（合入 88 条），以及 `xlsx严格*/smoke_*/mainui_*/topui` 等历史套件。
- **效果**：可自动化 520 条中，功能操作口径已覆盖 472 条（90.77%），入口烟测上界 519 条（99.81%）；剩余功能缺口 48 条。

**未合入与修复（历史）**
- 未合入：`case_2018701`、`case_2018753`、`case_2018851`、`case_2018695`（智能语义搜索）——需要稳定单窗口会话与搜索服务隔离。
- 已修复：回收站夹具改用 `$HOME`（`gio trash` 不支持 /tmp）、复制地址前 `ctrl+a`、排序/分组断言语义一致化、避免 `session_start` 断言 `sleep` 竞态。
