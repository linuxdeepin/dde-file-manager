## Naming Rules

- Use `setAccessibleName()` AND `setObjectName()` for QWidget subclasses
- For QAction/QShortcut (pure QObject, not QWidget): `setObjectName()` only
- Names: PascalCase, English, max 64 chars, alphanumeric + underscore only
- When both calls are needed, use the SAME name string for both
